## 🌟 Key Features & Architectural Highlights

* Built at the **Built with AI Bootcamp** organized by **Hack2Skill x Google for Developers**.
* Bidirectional audio voice streaming with low-latency conversational AI.

### 🌀 2. 3D Igloo Particle Stage & Morphing Vortex (`igloo-contact.js`)
* Built with **Three.js WebGL** featuring a metallic torus stage podium with continuous rotation and cursor parallax.

## ⚡ Quick Start & Local Setup

### Prerequisites
* **Node.js** (v18.0.0 or higher)
* **npm** (v9.0.0 or higher)

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/ianuj-yadav/Anuj-Portfolio.git

# 2. Navigate to project directory
cd Anuj-Portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

The application will be running live at `http://localhost:5173`.

### Production Build
```bash
npm run build
```
